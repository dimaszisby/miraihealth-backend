### Helper placement considerations

- `__tests__/integration/helpers/test-utils.ts` now exports `api`, `createTestUser`, etc. Future integration suites can continue to reuse it, or we can promote it into a dedicated `tests/support/integration.ts` module with an alias (e.g., `@/tests/integration-helpers`).
- If we add new shared helpers later, prefer absolute imports so future moves remain trivial.
